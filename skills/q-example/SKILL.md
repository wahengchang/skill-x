# q-example

skill-q 的安裝驗證範例，同時作為 `q-*` 技能的最小樣板。

## Instructions

1. 當使用者要求測試 skill-q 時，簡短回覆「skill-q 已正常運作」。
2. 不要額外執行指令或修改檔案。

新增自己的技能時，複製這個資料夾、改名為 `q-<name>`，並讓 frontmatter `name:` 與資料夾同名。命名與提交規則見 `CONTRIBUTING.md`。
